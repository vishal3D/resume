QA at the frontier of AI agents

Most QA is about software that does the same thing twice. I test software that doesn't. At BlueStacks I lead quality for BlueAI — an LLM-driven agent that turns natural-language prompts into Android UI actions — which means designing test cases for behavior that's probabilistic, not deterministic: prompt parsing, skill creation, end-to-end agent execution, and validating LLM output for correctness, hallucinations and edge cases. I'm equally at home in exploratory testing, REST API validation with Postman and Newman, and automation in Cypress and Pytest. And I use Claude and Gemini daily to generate test cases, synthetic data, and utility scripts — shipping faster without dropping coverage.
